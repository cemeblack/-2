# AutoShutdown

Маленькая программа для Windows 10/11:

- запускается сама при входе в Windows;
- каждый день в **21:00** выключает компьютер;
- за **час** до выключения показывает в правом нижнем углу таймер обратного отсчёта
  (в последние 5 минут он становится красным).

Таймер всегда поверх других окон, но не мешает: не забирает фокус, клики проходят
сквозь него, его нет на панели задач.

Ничего устанавливать не нужно: программа собирается встроенным в Windows
компилятором C# (.NET Framework 4).

## Установка

1. Скачайте репозиторий (Code → Download ZIP) и **распакуйте** архив.
2. Дважды щёлкните `install.bat`.
   Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите
   «Подробнее» → «Выполнить в любом случае».

Скрипт соберёт программу в `%LOCALAPPDATA%\AutoShutdown\AutoShutdown.exe`, добавит её
в автозапуск и сразу запустит. Права администратора не нужны.

## Настройки

В начале файла `AutoShutdown.cs`:

| Параметр | По умолчанию | Что значит |
|---|---|---|
| `ShutdownHour`, `ShutdownMinute` | `21`, `0` | время выключения |
| `WarningMinutes` | `60` | за сколько минут показывать таймер |
| `LateToleranceMinutes` | `5` | если в 21:00 компьютер спал и проснулся не позже чем через 5 минут — выключится сразу |

После изменения ещё раз запустите `install.bat`.

## Как это работает

- Если включить компьютер **после** 21:00, в этот день он не выключится —
  следующее выключение будет завтра в 21:00.
- Выключение принудительное (`shutdown /s /f`): программы закрываются без вопроса
  о сохранении. Для этого и нужен таймер — сохраните всё заранее.
- Отменить выключение на сегодня: Диспетчер задач → `AutoShutdown.exe` → «Снять задачу».
  При следующем входе в Windows программа снова запустится.

## Удаление

Дважды щёлкните `uninstall.bat` — программа остановится, удалится из автозапуска и с диска.
